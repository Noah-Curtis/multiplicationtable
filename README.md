### Let's look into this assignment!
There were lots of big ideas...
## The Big Ideas: 

* What did I **learn?**
* What went **well?**
* What was **difficult?**


Throughout this project, I learned a lot about variables and JavaScript. My experience was limited before this project, and through trial and error, I was able to learn how to piece things together to interact appropriately.

I enjoyed thinking about the possibilities of using JavaScript and other implementations I could use in the future. By building off of my knowledge of basic html and css, I can build websites that not only look good, but also allow for seamless user interaction.

Something that was challenging throughout this course was making a small typo that would throw off the course of my project. I found that when working in an interactive environment where every piece is connected, making one mistake often affected multiple aspects of my website, which made these errors more difficult to diagnose.
